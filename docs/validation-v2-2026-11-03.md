# 运行时纵向验证

本文件保留验证方法，不保留首次实际来源、个人目录、生产数据统计或真实模型对话。

## 验证范围

使用单一 Mastra 运行时和 RuntimeApi，通过合成场景核对：

1. 本人消息、来源事件、明确同意与任务执行事件各自的来源和身份。
2. 场景上下文、长期本人理解与代理方法记忆的隔离、纠正及撤回。
3. 来源新增、修改、删除、根目录暂不可用和重启后的去重恢复。
4. 原生操作提交、确认、未知结果、迟到回执、取消与关闭排空。
5. 旧数据的只读归档、导出和迁移，不让历史消息重新授予任务同意。

测试使用独立临时数据和离线供应商。涉及真实模型、私人资料或外部写入的检查须另有明确授权，并单独保管其证据。

产品边界与后续迁移统一记录在[README](../README.md)、[运行时说明](runtime-v2.md)和[内核契约](kernel-upgrade-2026-11-07.md)。

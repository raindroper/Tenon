# 核心链路验证约定

公开回归使用合成消息、隔离临时数据与模拟供应商，不保存实际用户的对话、账户、模型连接或用量回执。

## 程序验证

- 本人消息先持久化，再进入唯一运行时；不允许客户端注入助手角色。
- 观察、内部理解、方法学习与任务执行分别遵循产品契约。
- 任务须绑定有效的来源同意和资源授权；实际调用前重新核对版本与撤回状态。
- 输出、用量、操作回执、未知状态和恢复结果均有独立断言，不能由模型自述认证成功。
- 取消与关闭等待已接受操作排空；失败恢复核对稳定编号，不盲目重做外部操作。

运行核心检查：

```sh
npm run check
npm test
npm run build
```

## 证据边界

离线回归证明机制和数据边界，不证明真实模型的语义质量。真实模型与个人资料验收需要单独授权，原始样本、账户信息和发布现场记录不进入源码仓库。当前实现以[运行时说明](runtime-v2.md)和[内核契约](kernel-upgrade-2026-11-07.md)为准。

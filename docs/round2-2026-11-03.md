# 第二轮：收敛实现与个人代理闭环

> 历史实现与测试快照。用户随后明确：理解本人和能力进化并重，规划/日常提醒可自主，实际产出任务先获允许。原示例工作区任务链已从活动验收移除，不作为成长指标。当前定位见[README产品契约](../README.md#当前产品契约)，已落实的成长/许可边界见[当前运行说明](runtime-v2.md)。

本轮执行用户要求的“该删就删、该改就改”。目标是完成小型纵向链，而不是安装整套连接器平台。仅使用原有Mastra、SQLite/libSQL、文件观察和Git执行边界，没有新增运行时框架、数据库服务或付费后台。

## 当前数据流

1. 聊天、上传文本、反馈、目录变化或持久时间产生事件。
2. 已绑定事项的事件直接进入事项。无归属输入或整体回访由个人主代理读取小型有效个人理解和事项目录，选择已有事项、新建目标或等待。
3. 事项执行者保持自己的原生历史与工作记忆，按需检索当前事项的旧证据。不会因引用某个ID就获得其他事项全文。
4. 模型可从本人当前消息/反馈主动学习偏好、习惯和经验，带逐字证据及范围保存；外部文档不能作为本人人格的明确陈述。
5. 新的相关事项读取有效理解；本人明确纠正生成更高权威的新版本。不同领域、已撤回、过期或证据不可用的条目不注入模型。
6. 草稿、真实工作树回执和本地消息各按自身含义交接；只有通过已配置验收的工作才能走当前完成路径。

主代理和事项执行者均使用Mastra原生调用，不增加另一套长期代理框架。普通事项事件不额外走一轮全局规划。主代理的并行决策工具在副作用前同步领取唯一选择，失败后的创建intent仍沿既有journal恢复。

## 个人理解的边界

继续使用原生resource核心作为唯一持久权威，事项使用thread工作记忆。旧SharedFact格式兼容读取并在修改时进入版本链，不另写一张会互相覆盖的画像镜像。

条目包含类型、假设/明确陈述、case/domain/global范围、证据引用、有效时间、revision及取代关系。普通假设默认30天；未撤回当前内容预算160k字符，历史不占这个预算且每条最多8个旧版本，保留键总数最多64（包含撤回键）。撤回作为控制操作不会被容量阻挡，已有版本仍可恢复。模型上下文最多取16条，并剥离历史版本与原始摘录。普通自动学习限case/domain，不能自行晋升全局；本人在入口明确设置的范围可用于共享。

自然语言纠正必须来自当前事项的真实本人消息，或带correction/off_target信号的本人反馈，引用精确原文并指向已有key。旧证据不允许覆盖更新的纠正。完整语义是否理解正确仍由模型判断，因此仍允许用户直接纠正和撤回，不能把证据校验等同语义永远正确。

尚未启用OM、embedding或外部记忆平台。当前检索是有作用域的关键词/事件查找，尚无复杂的人格统计、长期语义关联或全历史自动巩固。

## 唤醒与生命周期

模型安排的事项时间不变。整体回访起始一小时；选择等待时默认逐渐延长到2/4/8/12小时，模型也可明确选择时间。实际进展可缩短过长退避，持续资料变化不会无限推迟已经安排的近期整体回访。这些是提供执行机会的低成本调度，不是固定生活任务路线。

取消、配置更新和关闭仍有明确屏障。已经开始的原生工具必须排空；人工改个人理解会先排空旧工作，但不改变用户原本运行/暂停意图。关闭还等待已接受的人工修改，避免数据库已关闭后迟写。

## 网页与使用

网页沿用现有风格，读取唯一`/api/state`，展示对话、当前事项、个人理解、真实目录来源、草稿和运行记录。新消息默认让代理归类；引用回复自动带原事项，当前事项也可手动选择。可以查看保存的工作状态、给消息/成果/事项反馈、纠正或撤回理解。历史恢复接口已提供；页面当前展示版本号与保留数量，尚未提供完整历史版本浏览器。

持续目录与上传文本分别展示。目录停用保留历史；完整资料遗忘仍未实现。草稿明确显示待核验。没有新增复杂工作台、插件市场或授权平台。

## 验证

新增纵向回归使用临时真实目录、原生Mastra和Mock模型，验证“未布置目标的资料事件→独立事项→文本草稿→对成果反馈→自动学习→重启→新相似事项体现学习”，同时检查无关领域不污染。它证明程序闭环，不证明真实模型已懂用户或目标必然有价值。

另有个人理解证据/失效/版本回归、无事等待与持久退避回归、并行决策与人工写入关闭边界回归。原先来源重绑、预算、撤权、工作树崩溃与取消排空等有效测试继续保留。

浏览器验收使用4318端口的隔离临时夹具及Mock模型，验证引用回复保留事项、暂停保存消息、纠正产生新版本、目录健康可见、切换事项不混入旧对话。界面证据为`.local/validation/`，图中内容均明确标为测试夹具，没有写入真实用户资料。

真实API推理本轮保持关闭。更广的代码执行、跨事项证据授权、全局语义优先级/截止冲突、外部生活连接器、远程通知和长期无人值守评估仍是后续工作。

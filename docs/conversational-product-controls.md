# 对话操作产品内部功能

本次替换仅能创建场景的对话入口，使聊天和页面共用 `RuntimeApi` 的场景、记忆、连接器命令。产品定位和任务执行边界不变：这里没有文件执行、安装、凭证读取或对外写入能力。

## 操作与授权

- `inspect_product` 查询真实对象及其 ID、版本和连接范围，替换原有单独的场景发现工具。结果有界，记忆历史须针对具体条目读取。
- `manage_product` 接受至多八个具体操作，绑定持久化的当前本人消息及其原始事件。被动资料、反馈事件、后台任务都拿不到该工具；历史或外部文字不能成为本轮授权。
- 指令及逐项回执保存在原 `Run.productControl` 中，没有新增可竞争的场景、记忆或连接器状态表。执行前重新核对本人消息来源和目标范围，实际数据仍由原生 API 管理。
- 普通操作不重复批准。账号登录及新增授权沿用原连接器交接；OAuth 回调地址只来自可信部署配置。本机无公网入口配置时使用已有连接器面板完成授权。密钥不进入工具参数、返回值或回执。

## 生命周期和恢复

模型调用仅受理指令，停止后续模型步骤。协调器将已接受操作纳入生命周期等待，等原模型队列项彻底退出才调用原有 API，防止场景归档或记忆纠正等待自身。等待连接器网络请求时，其他场景仍可交流。

每项操作区分未开始、执行中、完成、待本人处理、失败和结果未知。回执由真实 API 结果产生，不再追加模型调用。相同消息及同回合重复工具调用只记录一批指令；不会覆盖后续本人对场景的修改。多项操作不是数据库事务，逐项报告实际结果，不承诺整批回滚。

重启后未开始的指令标记未执行；执行中断但不能证明完成的指令标记未知，不自动重做。已保存回执按稳定消息 ID 恢复。取消和关闭等待已接受的原生操作及结果保存；已记录受理不作为完成证明。

## 场景与背景

删除的默认含义为归档，复用原场景 `cancelled` 状态，保留 ID、主题色、历史、资料和导出能力。恢复只恢复场景；旧任务和提醒不会自动重启。界面沿用原导航，当前正在阅读的归档场景和通用入口可继续显示。

背景仍只有原生场景 `objective` 一份可写正文，`backgroundSources` 仅保存出处：本人消息、原始事件、所属场景、时间和内容指纹。现有对话模型按需使用 `recall` 整理相关事实，无额外摘要模型。引用只能来自当前消息或本轮已回查的有效本人原话。

生成背景在使用前重新核对来源及记忆撤回范围。任一出处失效时整份自动背景停止用于推理，避免通过派生摘要重新带回旧理解。只改名或重新保存相同背景仍保留出处；本人实质编辑正文后成为本人编辑的背景。旧场景无需迁移，未带出处的原有正文保持原行为，旧历史不重写。

## 验证范围

离线回归覆盖：自然对话创建及背景出处、当前场景归档和恢复、记忆版本链、OAuth 交接、保存凭证后的文档连接、同步与断开、重名/未知对象的查找约束、来源失效、重复提交、重启、原生提交后故障、取消与关闭期间的等待、跨场景响应。测试使用隔离临时数据和网络阻断，不调用真实账号或付费模型。

2026-11-08 完整离线回归 659/659 通过，零失败、零跳过；`npm run check`、`npm run build` 通过。新增对话产品操作专项 18 项覆盖完整原生接口流程，取消、关闭和网络等待使用确定性阻塞点核验。测试工作目录由原测试启动器在工作进程退出后清理。

背景提取仍受既有回查次数、结果数和整轮步骤/时间预算约束；它是相关背景整理，不是无上限扫描整个历史。外部服务写入、通用电脑控制、永久删除和账号权限扩张没有在此工具中开放。

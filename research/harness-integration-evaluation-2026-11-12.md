# 本地执行器集成边界

本记录说明执行器选择与验证方法，不包含维护者的真实模型连接、任务样本、机器配置或调用用量。

Tenon 将项目执行交给内置的 Codex App Server；唯一 Mastra 运行时继续负责本人交流、资料、记忆和任务许可。执行器版本及分发摘要以[固定资源契约](../shared/codex-runtime.ts)为准。

## 集成要求

- 随客户端分发固定的执行器、运行时及必要许可证；启动前核对实际资源版本与完整性。
- 使用公开协议创建和恢复原生会话、处理工具请求、补充要求与中断。执行器会话不能创建新的任务同意。
- 任务上下文只接收当前授权范围内的资料。模型与资料连接经原任务授权核验；客户端不暴露长期供应商密钥。
- 插件与推荐目录同步关闭，原生配置采用严格校验。已有工具的运行不自动授予安装或启用新能力的许可。
- 工作区身份、要求版本、操作编号及回执持久保存。未知外部结果保留未知，不按网络错误自动重发。
- 暂停与取消依靠实际进程和回执排空，不把发送中断请求或关闭 stdin 当作完成证明。

## 验证方法

使用隔离的合成项目与脚本化模型响应，验证实际文件修改、Node 检查、许可钩子、越界拒绝、浏览器交互、截图与父子进程退出。覆盖补充要求、断线、日志去重、故障恢复和迟到回执；固定样例不构成模型能力排名。

原生子进程不一定经过 Node 的网络守卫，因此对测试中的远端 Git 协议另行拒绝，并检查实际生效的功能开关。真实模型效果评估需要明确授权及人工验收，私人样本和用量回执不提交到公开源码。

## 上游与许可证

采用维护中的公开接口；不修改上游私有模块。第三方许可随分发资源保留，相关资料见 [Codex App Server](https://developers.openai.com/codex/app-server)、[Codex 源码](https://github.com/openai/codex)、[OpenCode](https://opencode.ai/docs/) 与 [Playwright MCP](https://github.com/microsoft/playwright-mcp)。

当前项目集成合同见[本地执行说明](../docs/local-project-harness.md)。
